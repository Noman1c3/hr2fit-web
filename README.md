# HR2Fit — Human Resources Outsourcing Website

A modern, responsive, high-performance website redesign for **HR2Fit** ([hr2fit.com](https://hr2fit.com/)), an HR outsourcing provider serving small and mid-size businesses throughout Massachusetts and New Hampshire.

## 🚀 Key Highlights & Features

- **Executive Homepage Layout**: Modern aesthetic combining deep navy, ocean blue, and vibrant lime brand accents.
- **Hero & Value Proposition**: High-impact messaging centered around *"HR to fit your business"* and on-site HR assessment CTAs.
- **Interactive Service Explorer**: *"Smart HR for everyday business"* tabbed solution center with instant deep-dive details.
- **Leadership Showcase**: Dedicated section for founder Dr. Cindy Cushman with a transparent portrait cut-out.
- **Authentic Client Endorsements**:
  - Speech-bubble testimonial cards featuring real executive reviews.
  - High-resolution circular client photo avatars (`kimberly.png`, `scott.png`, `vesta.png`, `arrington.png`, `amie.png`).
  - Hands-free auto-scrolling carousel that automatically advances every 4.2 seconds and pauses on hover/touch.
- **Team Size Solution Finder**: Interactive headcount filter (`1–25`, `26–100`, `100+`) to tailor recommendations.
- **FAQ Accordion & HR Insights**: Expandable question panels and thought-leadership resources.
- **Elevated CTA Banner**: Multi-stop ocean gradient with ambient luminous glow and glassmorphism badges.
- **100% Responsive**: Tested across desktop, tablet, and mobile screen sizes (1440px, 1024px, 768px, 390px).

## 🛠️ Local Setup & Preview

Open `index.html` directly in any modern browser, or run a local static web server:

```bash
# Using Python
python -m http.server 3000

# Or using Node
npx serve .
```

Visit `http://localhost:3000/` to preview the site.
